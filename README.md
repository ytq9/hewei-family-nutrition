# 禾味日历

面向家庭的响应式菜单、菜谱与营养记录 PWA。手机端提供底部导航和大触控区域，电脑端提供宽屏菜单与健康档案界面。

在线体验：[hewei-family-nutrition.spiffy-aphid-8940.chatgpt.site](https://hewei-family-nutrition.spiffy-aphid-8940.chatgpt.site)

## 当前能力

- 今日与本周菜单、早餐/午餐/晚餐/加餐
- 菜谱、标签、备注、食材重量、可食比例和出品份数
- 标准 JSON 菜谱导入、导出及 GPT 生成模板
- 按份或按成品克数分配个人摄入
- 能量、三大营养素、膳食纤维、钠、钙、铁、钾及维生素 C/D 计算
- 家庭成员、代管档案和体征趋势
- 菜谱生成购物清单、单位换算和购买勾选
- 本机自动保存、JSON 备份导出与导入
- PWA 主屏幕安装和静态资源缓存

这是完全静态的本机版，不需要 CloudBase、数据库、账号或 API Key。菜单和健康数据保存在当前浏览器的 `localStorage` 中，不会上传服务器。清理浏览器数据或更换设备前，应先从“本机数据”导出备份。

静态网页不能安全地直接调用混元视觉：如果把腾讯云密钥写进网页，任何访问者都能读取。因此本版本采用手工录入和标准菜谱文件导入，不提供拍照或云端 AI 识别。

## 项目结构

```text
app/       页面、交互和业务逻辑
public/    PWA 图标、清单和离线缓存脚本
tests/     营养、菜单、购物与数据备份测试
worker/    Sites 部署入口
build/     Sites 构建辅助代码
```

## 本地运行

要求 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev:static
```

生成可部署的纯静态文件：

```bash
npm run build:static
```

构建结果位于 `static-dist`，可上传到任意静态网站托管服务；该目录属于生成产物，不提交到 Git。

验证：

```bash
npm test
npm run lint
```

复制 `.env.example` 为 `.env.local` 后，可以按需修改正式站点地址。环境文件不会提交到 Git。

## 本机数据说明

- 菜单、菜谱、成员、体征和购物清单会自动保存在当前浏览器。
- 不同浏览器、无痕模式和不同手机之间不会自动同步。
- 浏览器清理网站数据后，本机记录会丢失。
- “本机数据”入口可以导出完整 JSON 备份，也可以在另一台设备导入。
- 食材照片只用于本次编辑时预览，不写入备份，避免浏览器存储被大图片占满。

## 营养计算约定

- 食材营养 = 每 100g 营养 × 重量 × 可食比例 ÷ 100。
- 按份分配使用菜品总营养与出品份数；按克分配必须先记录成品重量。
- 任一食材缺少某项营养数据时，该项结果保持“不完整”，不会当作零。
- 已确认餐食保存快照，后续菜谱或食物数据修改不应追溯改变历史。
- 页面中的参考进度不构成诊断、治疗或疾病营养建议。

## 数据来源

演示食材保留 USDA FoodData Central 来源编号和版本。正式导入数据时应继续保留来源、版本和缺失字段，不批量复制版权状态不明确的数据源。
